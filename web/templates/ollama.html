API reference
Ollama's HTTP API on this server. Full docs ↗

        

          
List installed models
curl {{.Data.Ollama.BaseURL}}/api/tags

          
Show loaded models
curl {{.Data.Ollama.BaseURL}}/api/ps

          
Generate (one-shot)
curl {{.Data.Ollama.BaseURL}}/api/generate -d '{
  "model": "llama3.2",
  "prompt": "Why is the sky blue?",
  "stream": false
}'

          
Chat (messages)
curl {{.Data.Ollama.BaseURL}}/api/chat -d '{
  "model": "llama3.2",
  "messages": [{"role": "user", "content": "Hello"}],
  "stream": false
}'

          
Pull a model
curl {{.Data.Ollama.BaseURL}}/api/pull -d '{"name": "qwen2.5:1.5b"}'

          
Show model details
curl {{.Data.Ollama.BaseURL}}/api/show -d '{"name": "llama3.2"}'

        

      

      

        
Install or connect Ollama
VPSDeck shows instructions only and never executes these commands.

        

          
Linux service
Official installer and systemd startup.
curl -fsSL https://ollama.com/install.sh | sh
sudo systemctl enable --now ollama
curl http://127.0.0.1:11434/api/version
Official Linux guide ↗

          
Docker CPU
Persistent volume with automatic restart.
docker run -d \
  --name ollama \
  --restart unless-stopped \
  -v ollama:/root/.ollama \
  -p 11434:11434 \
  ollama/ollama
