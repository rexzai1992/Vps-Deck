Install or connect Ollama

VPSDeck shows instructions only and never executes these commands.

Linux service

Official installer and systemd startup.

curl -fsSL https://ollama.com/install.sh | sh
sudo systemctl enable --now ollama
curl http://127.0.0.1:11434/api/version
Official Linux guide ↗

Docker CPU

Persistent volume with automatic restart.

docker run -d \
  --name ollama \
  --restart unless-stopped \
  -v ollama:/root/.ollama \
  -p 11434:11434 \
  ollama/ollama
