Everything you need to run a VPS

Secure, self-hosted, and built for people who'd rather click than type.

▦

Live dashboard

Real-time CPU, RAM, disk, uptime, kernel, and IP — refreshed every few seconds without page reloads.

⇅

GitHub deployments

Clone repos, run fast-forward-only git pulls, trigger Docker Compose rebuilds — all from one button.

□

File manager

Explorer-style drag-and-drop, multi-select, inline rename, ZIP download, and a built-in text editor.

◉

Ollama monitor

See installed models, loaded models, VRAM usage, and run a prompt playground — all in one view.

⇄

Port monitor

Live TCP/UDP listener table with per-process names and automatic project-port association.

⚙

Advanced Mode

Full-filesystem Explorer unlocked by password re-confirm, with an inactivity timeout and full audit log.

Install on Ubuntu in one command

Creates a system user, builds the binary, configures systemd and Nginx.

git clone https://github.com/rexzai1992/Vps-Deck.git /tmp/vpsdeck-src
sudo bash /tmp/vpsdeck-src/scripts/install.sh
