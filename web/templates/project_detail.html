How to connect a domain

Make this project accessible on a public hostname.

  1. 1
    Point your DNS to this VPS

    In your domain registrar, add an A record for your hostname (e.g. app.example.com) pointing to this server's IP address. Allow a few minutes for propagation.

  2. 2
    Add a domain route in VPSDeck

    Go to Domains → Add managed route. Set the hostname, select this project, and click Create route.

  3. 3
    Test and apply

    Back in the Domains table, click Test to verify the Nginx config is valid, then Apply to reload Nginx and go live.

  4. 4
    SSL (optional)

    Once the HTTP route is live, run sudo certbot --nginx -d app.example.com on your VPS to obtain a free Let's Encrypt certificate. Certbot will update the Nginx config automatically.
